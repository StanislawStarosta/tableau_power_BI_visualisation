# 💐 Kwiatowa Przystań – Tableau vs Power BI (Comparative BI Project)

## 📌 O projekcie / Project Overview
Projekt prezentuje pełną analizę porównawczą dwóch wiodących narzędzi Business Intelligence: **Tableau** oraz **Power BI** na przykładzie danych fikcyjnej hurtowni kwiatów „Kwiatowa Przystań”. 

Dane do analizy zostały wygenerowane programistycznie za pomocą skryptu w języku **R**, a następnie przetworzone i zwizualizowane w obu środowiskach.

---

## 📂 Struktura plików / Repository Structure

* 📄 **[Kwiatowa Przystań.pdf](./Kwiatowa%20Przystań.pdf)** – Główna prezentacja projektu w formacie PDF (zawiera pełne porównanie dashboardów, wnioski i screeny).
* 📊 **[hurtownia_kwiatow.xlsx](./hurtownia_kwiatow.xlsx)** – Wygenerowany zbiór danych w formacie Excel.
* 🟡 **[Projekt.pbix](./Projekt.pbix)** – Interaktywny raport przygotowany w Power BI Desktop.
* 🔵 **[Projekt.twbx](./Projekt.twbx)** – Interaktywny raport przygotowany w Tableau Desktop.
* 💻 **[wizualizacja.R](./wizualizacja.R)** – Skrypt w języku R służący do generowania/przygotowania danych.

---

## 🛠️ Użyte technologie / Tech Stack
* **Business Intelligence:** Power BI, Tableau
* **Data Generation & Prep:** R, Microsoft Excel
* **Data Visualization Topics:** Sales Analysis, Inventory & BI Tool Comparison

---

## 🔒 Prywatność danych / Data Privacy
*Wszystkie dane wykorzystane w projekcie zostały wygenerowane syntetycznie przy użyciu kodu w języku R i nie zawierają prawdziwych danych osobowych (PII).*
